# Airline Transferability Research

Hand-verified research on passenger name change / ticket transferability policies across 52 carriers.

> **Disclaimer:** This document is internal research compiled from official airline policy pages and,
> where noted, secondary sources. Fees and conditions can change without notice. Always re-check the
> source URL before relying on a figure. This file is documentation only — it does not drive any
> database or application logic.

## Status legend

- **Fully transferable** — the airline permits changing the passenger to a different person, subject to a fee.
- **Partially transferable** — permitted only for certain fares, channels, or conditions.
- **Not transferable** — passenger substitution is not allowed; only spelling/legal-name corrections.
- **Ambiguous** — published policy is unclear; requires direct confirmation with the carrier.
